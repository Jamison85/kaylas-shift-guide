# Till mobile runtime V2

Uses transparent, pre-rendered articulated frames from the V2 rig and the definitive 11461.png still. No WebGL requirement, extra route, or interactive overlay. Existing Guide tasks, copy and navigation remain unchanged.

Release subset: idle breathing/blink, wave, pointing, explanation, nod, thumbs-up, shift celebration and clipboard hold. 336 × 453 px, ~18 fps source; one-shot gestures settle to idle. Reduced motion, hidden tabs and offscreen actors use the still. All encoded WebP frames decoded and checked for silhouette clearance, including extended hands. Manifest records source and encoded frame counts and bounds. The existing app service worker precaches build output.

Deferred: directional turns, climbing/hanging, complex object contacts and advanced locomotion. V2 lab is not shipped. CPU-rendered frame samples visually inspected; physical phone performance not verified.
